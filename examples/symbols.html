01 / Your own SVG icon assets

The icon contract changes size and alignment, never the path, stroke width, or fill. It accepts an SVG directly or inside a wrapper.

Buttons are disabled because this is a static illustration, not an interactive search or sync application.

02 / Hover and focus icon motion

Six opt-in, CSS-only motion presets. Hover or focus a preview button to animate; buttons only demonstrate visual feedback, not application actions. Reduced-motion preferences disable every effect.

Add a modifier such as syn-icon--spin. Add syn-icon--on-interact for hover/keyboard-focus activation. See configuration and accessibility guidance.
