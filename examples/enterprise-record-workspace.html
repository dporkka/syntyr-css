Host application responsibilities

This is a static, copy-owned source-candidate composition. A backend computes grouping, filters, summary values, pagination and authorization from the same query. Native disclosure is not a saved view or a filter.

For real list-to-detail navigation and safe local-only record edits, use the runnable Go resource workbench. For an editable form, reuse the form-state contracts; pending, failed and conflict states must reflect actual application outcomes.

Requires matching unreleased alpha.5 source stylesheets. The sample contains no real customer data, JavaScript, persistent application state or remote runtime assets.
