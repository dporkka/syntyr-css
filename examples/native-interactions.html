Native interaction recipes

Five real browser patterns, no JavaScript, no custom widgets, no new component class names. These previews are static; a server or host application owns actual search results, data changes, and calculations.

Exclusive accordion

Related disclosures share one name, so opening one closes the other without an application state machine. Use a unique name per group.

Which components need JavaScript?

The browser handles these controls natively. A product may still need JavaScript for data-dependent behavior.

Can I use server-rendered HTML?

Yes. Return full pages, HTMX fragments, or regular links and forms from your server.

Does Syntyr replace focus management?

No. Native dialog and disclosure behavior remains owned by the browser.

Confirmation dialog

Native invoker commands open a modal dialog in supporting browsers. This is a non-mutating choice demo: method="dialog" closes the dialog; it does not submit a destructive action or save changes to the server.

Datalist suggestions and grouped select

Suggestions are not a custom combobox. Users may enter their own text; use select when values must be restricted to an allowed set.

Meter and output
