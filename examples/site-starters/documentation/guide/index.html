Guide / 01

Write your first field note.

Use ordinary text files and a small set of predictable conventions. This is a fictional format, not an executable application.

File layout

Keep each notebook in its own folder. A short, descriptive filename is easier to manage than an opaque identifier.

field-notes/
  observations/
    sample-note.md
  README.md

First note

Record the observation in plain text. Give it a title and date, then describe what you saw and what you still need to verify.

# Example observation
Date: 2026-01-12
Status: draft
