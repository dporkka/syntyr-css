What makes a website maintainable?

A website is easier to keep when its inputs, outputs and dependencies remain understandable.

Prefer ordinary files

HTML, CSS and plain-text content can be inspected without a specialized runtime. Keep the content separate from deployment mechanics.

Keep links stable

A URL is a public promise. Choose paths carefully and test them when a site is moved into a subdirectory.

Build only what you need

Introduce a generator for a concrete problem: recurring layouts, many documents, or indexing. The output should still be something the author owns.
