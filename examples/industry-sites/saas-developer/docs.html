02 / Observability

Make failures diagnosable.

Show request IDs, error codes, retry behavior, status pages, and documented limits once verified.

Operational documentation checklist

  • Document latency and rate limits
  • Explain idempotency and retries
  • Give actionable error examples

03 / Security

Document actual controls.

Security pages should link to tested and approved policies, not inherited marketing claims.

What to verify before launch

  • Authentication and key rotation practices
  • Data retention and deletion procedures
  • Incident reporting and contact process
