# Syntyr CSS — components and composition index

> Source-tree reference for Syntyr 0.3.0-alpha.5 (unreleased candidate). Use the published 0.3.0-alpha.4 CSS API when building against the stable alpha.4 distribution. These docs may contain classes absent from alpha.4.

Syntyr is CSS, not a JavaScript component framework. Load the required CSS modules, scope content with `.syn-root`, and preserve native HTML/ARIA semantics.
