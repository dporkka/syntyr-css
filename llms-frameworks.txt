# Syntyr CSS — frameworks and platforms index

> Source-tree integrations may describe unreleased v0.3.0-alpha.5 features. The published immutable release is v0.3.0-alpha.4. Syntyr is CSS; it does not provide framework-specific JavaScript components, application state or network handlers.

## Choose and install correctly

- [AI quickstart](https://syntyr-css.pages.dev/docs/ai-quickstart.md): Published-release CSS and class examples.
- [Distribution guide](https://syntyr-css.pages.dev/docs/distribution.md): Pin immutable assets; do not mix alpha.4 and alpha.5.
- [Published alpha.4 contract](https://syntyr-css.pages.dev/v/0.3.0-alpha.4/llms.txt)
- [Agent integration](https://syntyr-css.pages.dev/docs/agent-integration.md): Portable Skill, optional offline install and validation.
- [Framework integrations](https://syntyr-css.pages.dev/docs/framework-integrations.md): React, Vue, Svelte, server-rendered HTML, HTMX and more.
- [HTMX components](https://syntyr-css.pages.dev/docs/htmx-components.md): Copy-owned server-rendered patterns; source candidate.
- [Live HTMX playground](https://syntyr-css.pages.dev/docs/htmx-playground.html): Read-only Pages Function demo with self-hosted docs-only JavaScript (not included in Syntyr CSS).
- [Native browser APIs](https://syntyr-css.pages.dev/docs/native-browser-apis.md)

## Output contract for coding agents

Use `className` in JSX and normal class attributes in HTML; keep form handlers and state in the host framework. Validate class names against the installed CSS version and module, and test accessibility in a real browser.
