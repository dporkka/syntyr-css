SYNTYR / OPTIONAL HTMX / SERVER HTML

Try real server-driven components.

Type to search, change sorting, or follow page links. These controls make real GET requests to a Cloudflare Pages Function. No database, authentication or account is involved.

Demonstration only: read-only, fictional OOH customer data. This example uses the unreleased alpha.5 Syntyr source candidate and a separate, self-hosted HTMX 2.0.11 script. Neither is a required Syntyr dependency.

See what the server returns

A normal GET returns a full HTML document. The same endpoint returns only the results fragment when it receives HX-Request: true, including new table rows, sort state and pagination links. HTMX history restoration always receives a complete document.
