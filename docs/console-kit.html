What the private prototype includes

  • Twelve private layouts: eight core screens (overview, resources, details, create/edit, settings, team, billing and sign-in), governed approvals, and three CRM compositions
  • Grid, Noir and Studio colorways, responsive and keyboard-friendly markup, plus examples of empty/error states
  • Original HTML/CSS and implementation notes for server-rendered applications
  • No forced vendor framework, telemetry, JavaScript widget bundle or runtime dependencies

No delivery date, support plan or final license is offered yet. All essential components and all free CSS themes remain MIT and free. The future premium license would apply only to new, separately authored page compositions.

Current status and buyer boundaries

Included in the private prototype

Original static layouts, theme variations, responsive markup and synthetic sample content. Developers must still integrate them into their chosen backend.

Not implemented

Authentication, actual payments, persistence, server-side filters, live charts, authorization and customer data are not part of this UI kit. No live SaaS product is being offered.

Licensing and purchase status
