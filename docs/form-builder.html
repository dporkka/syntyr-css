    Progressive enhancement, by default

    Native labels, fieldsets, required, input types, GET/POST, and full-page submissions work without client JavaScript. Add HTMX, Alpine, React, or your own fetch handler later if you need inline results, conditional sections or multi-step flows.

    Publishing requires a working submission endpoint. Validate and sanitize on the server, protect state-changing actions against CSRF, limit uploads, and provide a server-rendered success or error response. Client-side constraints alone are not security controls.
