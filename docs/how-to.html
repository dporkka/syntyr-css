How to build with Syntyr.

Practical, task-focused steps. Each example opens in the CodeMirror playground so you can edit native HTML, switch themes, and inspect responsive layouts without installing a framework.

The source examples are MIT-licensed and represent the unreleased alpha.5 candidate. Check published release compatibility. Syntyr styles interfaces; your application supplies backend behavior, data and authorization.
