01 / Get started

COPY CSS / ZERO NPM / MIT

PUBLISHED ALPHA.4 / SOURCE ALPHA.5

Use native HTML. Ship nothing extra.

Start with the immutable published v0.3.0-alpha.4 stylesheet. That release includes Grid, Noir and Studio themes. The current source preview is an unreleased alpha.5 candidate with seven palettes: use it only when testing experimental changes, not as a pinned production release.

PUBLISHED ALPHA.4 CSS UNRELEASED ALPHA.5 PREVIEW RELEASE FILES 
<link rel="stylesheet"
      href="https://syntyr-css.pages.dev/v/0.3.0-alpha.4/syntyr.core.css">

<section class="syn-root"
         data-syn-theme="grid">
  <button class="syn-button
           syn-button--primary">
    Initialize
  </button>
</section>

The pinned URL above works for a quick trial; for production, download the tagged release and self-host the stylesheet at a path such as /css/syntyr.core.css. Additional modules are opt-in. See the customization guide, distribution guide, and MIT license.

04 / DISCLOSUREDETAILS
Why real HTML?

Buttons, forms, disclosures and popovers retain native keyboard and accessibility behavior.

Does it require Node or React?

No. Copy a CSS file and use any HTML renderer.

Can themes nest?

Yes. Set data-syn-theme="noir" on a section to override the Grid palette inside it.

08 / Engineering principles

BUILT FOR PRODUCTION AUDITS
LOW ENTROPY

Just CSS

No browser JS, no external assets, no runtime package dependencies. Python only builds distributable files.

PLATFORM FIRST

Native controls

Real button, dialog, popover, select, details, input and progress. No faux ARIA tab or combobox implementations.

PROGRESSIVE ENHANCEMENT

Optional effects

Decorative glows and grids are isolated from core styling; reduced-motion and forced-colors are respected.
