SOURCE PREVIEW / NOT A PUBLISHED RELEASE

Unreleased alpha.5 component examples

These are unreleased alpha.5 source examples. With JavaScript enabled, the release selector provides a published alpha.4 view limited to examples with matching CSS selectors and modules. The check does not certify visual appearance, accessibility, or interactive behavior.

Published alpha.4 selection checks CSS module and class coverage, not full visual or browser compatibility. For production, self-host the pinned CSS.

Install published alpha.4 Read release compatibility guidance

Load syntyr.core.css and place components within a syn-root scope. The examples below use the existing component API—no hydration or framework wrappers. Optional recipe, geometry and visualization examples require the named CSS module after core, or the all-in-one stylesheet.

For larger tables and enterprise-style interfaces, compare the read-only data grid example, accessible data tables and data grid integration guidance. These examples do not implement application sorting, virtualization or persistence.

For responsive layout patterns, see the intrinsic layout cookbook: fluid spacing, stacks, wrapping clusters, sidecars and grids, all with copyable HTML.

For additional native patterns see all HTML controls, semantic compositions, and browser-native overlays. Advanced page compositions are documented separately.

Browser support and accessible fallbacks

Support depends on the browser feature, not the Syntyr theme. These are implementation notes, not a compatibility certification or promise of identical behavior in every engine.

FeatureOlder browsers and fallbacksReference
HTML Popover APIIf an invoker cannot open the popover, critical content needs an ordinary link or a disclosure alternative.MDN Popover API
