Install in two steps

From plain HTML to polished UI.

Download the published, version-pinned core CSS, then add the stylesheet and Syntyr classes to your page. No build tool or component runtime required.

Release status: alpha.4 is the published download. This website also previews the unreleased alpha.5 source candidate, so not every showcased style is in alpha.4. Self-host the pinned CSS in production.

01 Download the pinned stylesheet

curl -fsSLo syntyr.core.css https://syntyr-css.pages.dev/v/0.3.0-alpha.4/syntyr.core.css

02 Include it alongside your HTML

<link rel="stylesheet" href="./syntyr.core.css">
<main class="syn-root" data-syn-theme="studio">
  <button class="syn-button syn-button--primary">
    Continue
  </button>
</main>

Example assumes the HTML file and downloaded CSS file share a directory. See the guide for other hosting layouts.

Syntyr CSS / FAQ

Frequently asked questions

Clear answers about using a CSS-first design system, release compatibility and where other tools may fit better.

What is Syntyr CSS?

An MIT-licensed CSS-first design system for scoped, semantic HTML components and reusable SaaS interfaces. It is not an application or widget runtime. Browse components.

Does Syntyr require JavaScript or a build tool?

No. You can self-host prebuilt CSS and use native HTML. Rich interactive widgets, state and application logic still need the browser or application framework. Read the integration guidance.

Can I use it with React, WordPress, Shopify or Astro?

Yes where the platform allows custom CSS and HTML, but hosting constraints and framework resets must be checked. Framework guide and site-builder guide.

Is Syntyr free for commercial websites?

The core is MIT-licensed. Optional commercial products are separate. Check the license and products and roadmap.

Which version should I install?

v0.3.0-alpha.4 is the published immutable release. The alpha.5 source candidate is unreleased; pin a tagged stylesheet and verify classes against that version. Installation details.

How is it different from Tailwind or Bootstrap?

Syntyr supplies scoped components and design tokens; Tailwind emphasizes utilities, while Bootstrap provides a mature component ecosystem. The right fit depends on your build and interaction needs. Compare alternatives.
