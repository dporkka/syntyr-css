Responsive HTML design tester

Paste HTML or edit the included semantic component example, then preview at common mobile, tablet and desktop widths. The content remains local and runs in a script-disabled sandbox.

Configure the preview

The preview uses the local Syntyr core CSS. Custom HTML is not saved or sent to a server. Scripts, forms and top-level navigation are disabled inside the sandbox.

Enable JavaScript to edit the preview.

How to use this tool

Use the width presets to inspect whether a component reflows at small mobile widths and whether a wide layout creates horizontal overflow. The preview uses a real width-constrained iframe—not a scaled screenshot.

This is a local HTML preview, not a scanner for arbitrary website URLs. Remote pages may disallow framing via CSP or X-Frame-Options; validating full live websites requires a real browser test setup. For comprehensive accessibility, performance and page audits, see Websyt.dev.

Verify touch targets, keyboard navigation, text resizing, forms and assistive-technology behavior separately in the actual application.

Build with Syntyr

Use the generated CSS with semantic HTML and Syntyr components. These utilities run in your browser; using the resulting code does not require any tool JavaScript.
