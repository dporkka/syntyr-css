How image conversion works

Your browser downsamples the image and maps luminance to a glyph ramp, using an approximate monospace character aspect ratio. The file stays on your device. Braille mode uses density glyphs, not a dot-level Braille encoding. Transparent pixels are composited against black before inversion. Use Bayer for regular ordered texture or Floyd–Steinberg for error diffusion. Custom ramps accept printable ASCII, block and Braille characters. Preserve image RGB colors for HTML, SVG and ANSI truecolor; plain text contains only characters. ANSI files contain terminal color sequences and reset styling after every row.

Art is decorative by default. Add a meaningful text alternative if an exported graphic conveys information.
