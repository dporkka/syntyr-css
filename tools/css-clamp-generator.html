How to use this tool

clamp(minimum, preferred, maximum) returns a value between two bounds. The preferred value here is a linear interpolation across a viewport range; no media query or runtime script is required in the generated CSS.

Always consider browser zoom and whether the chosen minimum text size remains readable. Prefer relative units for font sizing, and test at 200% and 400% zoom. The generated example uses rem and vw and assumes the root font size is 16px; modifying that root affects the interpolation.

See Syntyr typography guidance and MDN's CSS clamp() reference.
