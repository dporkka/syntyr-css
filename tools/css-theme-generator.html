How to use this tool

The exported selector applies to a Syntyr root carrying the matching data-syn-theme attribute. Load the core stylesheet first, then paste the generated override into your application stylesheet. The output uses existing tokens: --syn-bg, --syn-surface, --syn-text, --syn-accent and --syn-on-accent.

The generator selects high-contrast black or white text for the main background and accent, but a single foreground token may not pass on every selected surface. It cannot validate every component, link, muted text, border or state; test those separately.

Syntyr's source-preview theme collection may differ from the published immutable release. For a richer editor, see the theme editor and release guidance.
