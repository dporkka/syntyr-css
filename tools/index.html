How to use this tool

Choose a tool, make changes in the controls, and copy the resulting CSS. The calculations and previews are client-side, with no URL scanner, account, telemetry or rate-limited API behind them. Scripts are optional site tooling; Syntyr CSS itself has no JavaScript dependency.

Automated contrast measurement evaluates specific color pairs, not full page accessibility. Screen reader usability, focus management, keyboard support and layout reflow still need to be tested in a real interface.

Build with Syntyr

Use the generated CSS with semantic HTML and Syntyr components. These utilities run in your browser; using the resulting code does not require any tool JavaScript.
